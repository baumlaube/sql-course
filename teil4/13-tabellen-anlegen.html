Tabellen anlegen und füllen

Teil 4 · Lektion 13 ⏱ ca. 35 Minuten

Ein Plan ist noch keine Datenbank. Mit CREATE TABLE legst du die Tabellen an, mit INSERT INTO füllst du sie. Genau so entsteht jede Datenbank – auch die von großen Apps. Wenn du dich bei einer App registrierst, läuft im Hintergrund ein INSERT.

↺ Weißt du noch? 2 Minuten

📖 Wörter für diese Lektion

Die SQL-Befehle bleiben englisch – so heißen sie in jeder Datenbank der Welt.

anlegen CREATEEtwas Neues erstellen, hier eine Tabelle.
einfügen INSERTEine neue Zeile in eine Tabelle schreiben.
die Werte VALUESWas in die neue Zeile kommt – in derselben Reihenfolge wie die Spalten.
verweisen auf REFERENCESSo schreibt man im CREATE TABLE, worauf ein Fremdschlüssel zeigt.
speichern die DateiDeine Datenbank als .db-Datei herunterladen, damit sie nicht verloren geht.

🐾 Szenario

Dein Plan für Pfotenglück steht. Heute wird daraus eine echte Datenbank. Erst übst du an einer Kopie der Muster-Börse, dann baust du deine eigene.

1 CREATE TABLE: eine Tabelle anlegen 7 Minuten

So legt man die Tabelle besitzer an. Jede Spalte: Name und Datentyp, durch Komma getrennt.

CREATE TABLE besitzer (
  id      INTEGER PRIMARY KEY,
  vorname TEXT,
  wohnort TEXT
);

INTEGER PRIMARY KEY macht id zum Primärschlüssel – und die Datenbank vergibt die Nummern dann selbst.

Jetzt du: Leg die Tabelle arten an – mit id (Primärschlüssel), name (Text) und fell (Text).

2 Fremdschlüssel anlegen: REFERENCES 5 Minuten

Bei tiere zeigen zwei Spalten auf andere Tabellen. Das schreibt man mit REFERENCES dazu:

CREATE TABLE tiere (
  id          INTEGER PRIMARY KEY,
  name        TEXT,
  besitzer_id INTEGER REFERENCES besitzer(id),
  art_id      INTEGER REFERENCES arten(id),
  hobby       TEXT
);

3 INSERT INTO: eine Zeile einfügen 7 Minuten

In Klammern die Spalten, nach VALUES die Werte – in derselben Reihenfolge. Text in Anführungszeichen, Zahlen ohne. Die id lässt man weg.

INSERT INTO besitzer (vorname, wohnort) VALUES ('Mia', 'Augsburg');

Jetzt du (an einer Kopie der Muster-Börse): Lisa aus Landshut meldet sich an. Füge sie in besitzer ein.

Und ihr Tier: der Hamster Krümelmonster (Art-ID 9) gehört Lisa (sie bekommt die ID 11). Hobby: Laufrad. Füge ihn in tiere ein – nur die Spalten name, besitzer_id, art_id, hobby.

INSERT INTO tabelle (spalte1, spalte2) VALUES (wert1, wert2)
Gleich viele Spalten und Werte, in derselben Reihenfolge.

4 Deine Börse bauen 12 Minuten

  1. Öffne deinen Plan (.sql aus Lektion 12) mit „Datei öffnen“ – oder schreib die CREATE TABLE-Befehle selbst.
  2. Fülle die Tabellen mit INSERT INTO: erst Besitzer und Arten, dann die Tiere (die verweisen ja darauf).
  3. Am Ende der Stunde: „Als Datei speichern“. Diese .db-Datei ist deine Abgabe.

✓ Kurz-Check 3 Minuten

Merke

  • CREATE TABLE name (spalte TYP, …) legt eine Tabelle an. Primärschlüssel: id INTEGER PRIMARY KEY.
  • Fremdschlüssel: besitzer_id INTEGER REFERENCES besitzer(id).
  • INSERT INTO tabelle (spalten) VALUES (werte) fügt eine Zeile ein. Die id vergibt die Datenbank.
  • Reihenfolge beim Füllen: erst die Tabellen, auf die verwiesen wird (Besitzer, Arten), dann die Tiere.
  • Speichere dein Projekt als .db-Datei – der Browser allein ist kein sicherer Ort.
